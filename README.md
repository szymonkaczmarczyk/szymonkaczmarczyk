I live somewhere between web development and marketing. I like building things people actually click, and
figuring out why they click.

**Things I'm into**

- 🎬 Interfaces that feel alive - motion, typography, clean minimal design
- 🤖 Automating everything I do more than twice - scripts, bots, AI workflows
- 🛒 E-commerce from the inside - stores, marketplaces, integrations, what makes people buy
- 🌐 How the internet works under the hood - networks, security, infrastructure
- 📊 Data for fun - predicting races and matches just to see if the model beats my gut

**What I'm trying to do**

the way - design, code, tests and docs. Right now I'm going deeper into networking, security and systems that
scale.
